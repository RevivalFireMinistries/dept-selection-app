Design Decisions

What changed

  • Hub screen: Departments summary + upcoming events + action grid. Everything at a glance, nothing overwhelming.
  • Bottom sheets for department details, RSVP, and appeals — keeps context without navigating away.
  • Profile drawer replaces cluttered header — family switcher, poster requests, appeals all in one menu.
  • Meetings moved to a dedicated screen accessed via "Coming Up" → "See all".
  • Poster requests moved into the profile menu — they're infrequent actions, not daily use.

Why it's better

  • Before: Everything visible at once — departments, meetings, poster requests, HOD tools, appeals all stacked vertically. Long scroll.
  • After: 3 zones: status (departments), upcoming (time-sensitive), actions (things you can do). Secondary features behind profile menu.
  • Contextual: Appeal button only appears when window is open. Edit Selection only when not locked. HOD section only for HODs.
  • Familiar patterns: Bottom sheets (Maps/Uber), profile drawer (most apps), action grid (banking apps). Zero learning curve.

Information Architecture

Portal Home (Hub)
├── Status Card — departments at a glance (tap → bottom sheet detail)
│   ├── Approved departments (chips)
│   ├── Pending indicator
│   └── Appeal hint (when window open)
│
├── Coming Up — next 2-3 time-sensitive items
│   ├── Meeting with RSVP prompt
│   ├── Service you're participating in
│   └── "See all" → Meetings dedicated screen
│
├── Quick Actions (2x2 grid)
│   ├── Submit to Projector
│   ├── Request Poster
│   ├── Appeal (only when window open)
│   └── Edit Selection (only when unlocked)
│
├── HOD Card (only for HODs) → HOD members screen
│
└── Profile Menu (avatar tap → slide drawer)
    ├── Family profile switcher
    ├── My Details
    ├── My Poster Requests (with badge count)
    ├── My Appeals
    └── Log Out
